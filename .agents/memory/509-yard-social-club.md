name: 509 Yard social-club direction
description: Visual direction for the Lakou Domino rebrand and related screens.

For 509 Yard, Mòpyon follows Tic-Tac-Toe, then Box (Dots and Boxes-style), Kay (Mancala-style), Chess, Dame (Checkers), Scrabble-style word games, Four in a Row, Filler, and Block Drop (a Tetris-style falling-block game). Yard Mode is Ultimate Tic-Tac-Toe: nine small boards in a large board; a move routes the opponent to the corresponding small board, with free choice when that target is already closed. Mòpyon is five-in-a-row on intersections; marks persist and players can start anywhere. Use a 15×15 intersection board as the current adjustable default because the user was unsure of the final size. Use a restrained charcoal and black interface with a bright green game accent, white/light-gray text, and subtle borders. Keep the lobby and table low-glare, with dark surfaces and enough tile contrast for play. Keep the logo compact with clear left padding. Keep domino play and social flows central; avoid generic dark-purple game-dashboard styling, decorative scenery, and oversized promotion. Use visual references for hierarchy and mood, not literal copy. Use the supplied 509 Yard mark rather than inventing a new logo. The logo must be a transparent cutout, with no black rectangle baked into the asset or added in CSS.

**Why:** The user supplied a green-accented dashboard reference as inspiration, not a template to copy; they also asked for a smaller, padded logo and said the bright game screen hurts their eyes. They defined the game order and rules.

**How to apply:** Carry the same visual language across the lobby, auth, rules, waiting room, live table, and mobile layouts while preserving existing behavior, routes, and API contracts.
