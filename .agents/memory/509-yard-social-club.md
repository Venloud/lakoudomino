For 509 Yard, use a restrained charcoal and black interface with one bright red accent, white/light-gray text, and subtle borders. Keep logo-derived green/yellow limited to the mark and game pieces, not broad UI surfaces. Keep domino play and social flows central; avoid generic dark-purple game-dashboard styling, decorative scenery, and oversized promotion. Use the supplied 509 Yard mark rather than inventing a new logo. The logo must be a transparent cutout, with no black rectangle baked into the asset or added in CSS.

**Why:** The user later shifted the 509 Yard redesign to black/charcoal with a single bright red accent, while keeping the games and requiring the logo to remain a transparent cutout.

**How to apply:** Carry the same visual language across the lobby, auth, rules, waiting room, live table, and mobile layouts while preserving existing behavior, routes, and API contracts.
